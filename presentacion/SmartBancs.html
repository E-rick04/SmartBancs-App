Recomendación de calidad

Corregir primero los registros rechazados: completar montos, revisar fechas y monedas, y resolver IDs duplicados antes de volver a ejecutar el ETL.

El ETL no modifica saldos ni importa datos a las cuentas.

06 — API
Verificabilidad

Rutas claras.
Estado observable.

FastAPI publica la documentación interactiva. La API expone salud, métricas y rutas de operaciones.

Rutas principales

POST /transactionstransferir
GET /transactions/{id}consultar
POST /etl/runvalidar CSV

Operación y diagnóstico

La API publica /health y /metrics; PostgreSQL registra consultas lentas y esperas de bloqueo. Las recomendaciones provienen de un servicio independiente.
